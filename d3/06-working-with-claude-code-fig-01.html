Figure 5.1 — Vague vs four-move prompt

Same humanitarian-funding dataset. Nine words on the left, two hundred on the right.

Vague prompt (9 words)
"Make a bar chart of humanitarian funding by sector."
  • y-axis starts at $40M, not zero
  • bars uniform — no rank reinforcement
  • source-file order, not sorted by value
  • long labels crowd horizontally
  • no value labels — reader counts ticks
Four-move prompt (≈ 200 words)
Show → Say → Constrain → Verify
  • zero baseline (proportional ink, ch. 5)
  • sorted descending (effectiveness)
  • luminance redundancy on funding
  • value labels at bar ends
  • horizontal orientation handles long labels

What 200 words buys: the upstream channel decomposition becomes the artifact's structure.
