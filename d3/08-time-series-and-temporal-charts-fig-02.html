Figure 8.2 — The seven temporal chart forms

One thumbnail per form. Each names its primary channel and the question it answers best. The eighth card collapses the decision rule.

LINE CHART
Channel point position
Use when trajectory — slope, inflection, trend
AREA CHART
Channel area (zero baseline)
Use when magnitude — how much accumulated
STACKED AREA
Channel position + area
Use when composition + total trajectory
STREAM GRAPH
Channel centered area
Use when rhetorical rise and fall
SPIRAL PLOT
Channel position along a curve
Use when cyclic structure is the question
GANTT CHART
Channel position + length
Use when intervals, durations, overlaps
TIMELINE
Channel x-position only
Use when narrative sequence of events
Choose by channel
Trajectory → line
Magnitude → area
Composition → stacked
Cycle → spiral
Intervals → Gantt
Events → timeline
Rhetorical flow → stream
