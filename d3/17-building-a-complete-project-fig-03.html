The instruction budget is finite. Claude Code retains roughly 60 lines per file reliably. Combine both files into one and the rules at the bottom drop silently. The split disciplines that limit.

If the session involves any visual choice — colour, type, spacing — load both. If it is data processing, scale construction, or layout logic, load CLAUDE.md alone.
