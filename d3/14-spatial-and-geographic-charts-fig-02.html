Figure 14.2 — Four geographic forms

Reference grid: one card per spatial form. The data type and the reader's question choose the form — never the other way around.

CHOROPLETH
channel: color luminance · mark: region polygon
USE WHEN

Rate data (per capita, percent). Regions are roughly comparable in area.

DOT DENSITY
channel: point count · mark: single point per event
USE WHEN

Absolute count at point level. Spatial pattern is sub-regional.

BUBBLE MAP
channel: circle area · mark: circle at centroid (d3.scaleSqrt)
USE WHEN

Absolute magnitude per region. You need to sever the area-size distortion.

CONNECTION · FLOW
channel: line width · mark: line between locations
USE WHEN

Origin–destination data. Top-N filter mitigates spaghetti.
